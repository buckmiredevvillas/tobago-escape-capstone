# Tobago Escape – Vacation Planner

## Project Description

Tobago Escape – Vacation Planner is a web application designed to help visitors plan a vacation to Tobago.

The application will provide information about accommodations, attractions, beaches, restaurants, activities, and other useful travel information in one convenient location.

Kias Villa will be featured as one of the accommodation options available to visitors.

## Planned Features

- Home page with an introduction to Tobago
- Kias Villa accommodation information
- Photo gallery
- Tobago beaches and attractions
- Activities and things to do
- Restaurant and local food recommendations
- Vacation planner
- Booking or inquiry form
- Accommodation cost calculator
- Contact information
- Mobile-friendly responsive design
- Save favourite activities
- Possible AI Tobago travel assistant

## Project Goal

The goal of this project is to create an attractive, responsive, and user-friendly web application while demonstrating the skills learned in the Web Developer & AI program.
